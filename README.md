# Fatima Ideals Girls Academy — Frontend Preview

A responsive static website preview for client feedback.

## View locally
Open `index.html` in a browser, or run VS Code Live Server from the repository root.

## Deploy with GitHub Pages
1. Open the repository Settings.
2. Select Pages.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then Save.
5. Wait for GitHub Pages to deploy. The expected URL is https://aathal08.github.io/fatima-ideals-girls-academy/

## Notes
- Uses relative paths so assets load at a project-site URL.
- Images are stored in `images/`.
- The admission form is frontend-only for feedback. It does not send or store form submissions.
- To send enquiries to the school inbox, connect a backend or trusted form service before public launch.
- Please confirm the school’s official information and any curriculum/board affiliation before final publication.
